Lesson 0003

Connect React to an API

Load blog posts from a backend endpoint and render them in a React component.

The core idea

An API connection is a small pipeline: choose an endpoint, send an HTTP request, parse the JSON response, save it in component state, then render loading, success, and error states.

The five-step pattern

  1. Start with the API URL, such as /api/posts/.
  2. Call fetch(url) to ask the server for data.
  3. Check response.ok before trusting the result.
  4. Convert the response body with response.json().
  5. Put the data into React state so the screen updates.

A small API client

Keep request code outside the component so pages stay focused on display. 

// frontend/src/api/posts.js
const API_BASE_URL = import.meta.env.VITE_API_BASE_URL ?? "http://localhost:8000";

export async function getPosts() {
  const response = await fetch(`${API_BASE_URL}/api/posts/`);

  if (!response.ok) {
    throw new Error("Could not load posts");
  }

  return response.json();
}

Use it in React

// frontend/src/pages/Home.jsx
import { useEffect, useState } from "react";
import { getPosts } from "../api/posts";

export default function Home() {
  const [posts, setPosts] = useState([]);
  const [status, setStatus] = useState("loading");

  useEffect(() => {
    getPosts()
      .then((data) => {
        setPosts(data.results ?? data);
        setStatus("success");
      })
      .catch(() => {
        setStatus("error");
      });
  }, []);

  if (status === "loading") return <p>Loading posts...</p>;
  if (status === "error") return <p>Could not load posts.</p>;

  return (
    <main>
      {posts.map((post) => (
        <article key={post.slug}>
          <h2>{post.title}</h2>
          <p>{post.summary}</p>
        </article>
      ))}
    </main>
  );
}

What each part means

fetch

Sends the browser request to Django or another backend.

await response.json()

Turns the HTTP response body into JavaScript data.

useState

Stores posts and status so React can redraw the page.

useEffect

Runs the API call after the component first appears.

Practice: name the missing step

You called fetch(), got a response, and checked response.ok. What must happen before React can render the posts?
