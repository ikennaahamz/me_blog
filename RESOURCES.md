# CDM for Blog Resources

## Knowledge

- [MDN: Using the Fetch API](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch)
  Official MDN guide to making HTTP requests from browser JavaScript with `fetch()`. Use for: understanding the request, response, JSON parsing, and error-handling flow.
- [React: useEffect](https://react.dev/reference/react/useEffect)
  Official React reference that includes fetching data from an Effect. Use for: understanding why API calls usually run after render and how component state changes when data arrives.
- [Contentful: Content modeling basics](https://www.contentful.com/help/content-models/content-modelling-basics/)
  Official Contentful guide to content types, fields, entries, assets, and modeling iteration. Use for: understanding the shape of a content model before choosing tools.
- [Sanity: Introduction to schemas](https://www.sanity.io/docs/apis-and-sdks/introduction-to-schemas)
  Official Sanity guide to schemas as the foundation for structured content. Use for: learning how content structure can be defined in code.
- [Astro: Content collections](https://docs.astro.build/en/guides/content-collections/)
  Official Astro guide to managing structured content like blog posts using collections and schemas. Use for: a likely future path if this static blog grows into an Astro site.
- [Decap CMS: Folder collections](https://decapcms.org/docs/collection-folder/)
  Official Decap CMS guide to repeatable folder-based content collections. Use for: understanding Git-backed CMS models for blog posts.
- [Decap CMS: Widgets](https://decapcms.org/docs/widgets/)
  Official Decap CMS field/widget reference. Use for: mapping fields like title, date, body, image, tags, and draft status into an editor.
