CDM for Blog Glossary

The core terms for designing a content data model for a static personal blog.

CDM

A content data model: the named content types, fields, and relationships that describe the site's content independent of layout.

Content type

A repeatable kind of content, such as Post, Tag, Author, or Project.

Entry

One instance of a content type. For example, one essay is an entry of the Post type.

Field

A single structured piece of data on a content type, such as title, slug, publishedAt, or summary.

Relationship

A connection between entries, such as a post belonging to many tags or referencing one author.

Taxonomy

The controlled vocabulary used to group content. Tags and categories are common blog taxonomies.

Frontmatter

Structured metadata at the top of a Markdown file. It is the easiest first home for a static blog CDM.

Schema

A rule set that defines which fields are valid and what type of data each field expects.
