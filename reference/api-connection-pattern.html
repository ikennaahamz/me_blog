API Connection Pattern

Use this checklist when connecting a React page to a backend endpoint.

Request checklist

  1. Know the endpoint URL and the shape of the JSON it returns.
  2. Put request code in src/api/.
  3. Use fetch() or the project's chosen HTTP client.
  4. Check response.ok and throw an error for failed requests.
  5. Parse with response.json().
  6. Track loading, success, and error UI states.
  7. Render from state, not directly from the Promise.

Minimal shape

async function getThing() {
  const response = await fetch("/api/thing/");
  if (!response.ok) throw new Error("Request failed");
  return response.json();
}
